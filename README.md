# food-picture-01

Entry for the make.fun `food-picture-01` competition: the best-looking
food picture.

The entry is one image, `entry.png`: a gourmet plate of seared salmon
with a glossy glaze, asparagus and heirloom vegetables, herbs and edible
flowers, in soft natural window light. The program (`main.py`) only copies
the image to the output directory; the image is the entry.
